## MurText
功能介绍
**免费且无限制的转录！**  
只需一个快捷键，即可转录音频/视频文件和 WhatsApp 语音消息，并生成字幕文件。  
使用同一快捷键，还可以快速保存 WhatsApp 桌面应用中的其他文件。  

**快捷键：** `NVDA + Alt + Q`  

## 功能特点
- 转录在您的计算机本地完成，文件不会上传到互联网。  
- 安装后，即使离线也能进行转录。  
- 没有文件大小或时长限制。
- 说话人识别功能。
- 自动字幕生成功能。  
- 快捷键功能多样：  
	- 在 WhatsApp 中转录语音消息。  
	- 对于其他文件类型，将文件保存到默认目录。
