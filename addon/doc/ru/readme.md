## MurText
Дополнение NVDA для приложения MurText, которое преобразует аудио/видео файлы и голосовые сообщения WhatsApp в текст на более чем 100 языках.
Бесплатное и неограниченное преобразование речи в текст! Одним сочетанием клавиш мгновенно преобразуйте аудио/видео файлы и голосовые сообщения WhatsApp в текст и создавайте файлы субтитров. Используйте то же сочетание клавиш, чтобы быстро сохранять другие файлы из приложения WhatsApp для рабочего стола.

## Возможности

- Транскрипция выполняется локально на вашем компьютере. Файлы не загружаются в интернет.
- После установки вы можете транскрибировать даже без подключения к сети.
- Нет ограничений по размеру или длительности файла.
- Функция распознавания докладчиков.
- Автоматическое создание субтитров.
- Горячая клавиша многофункциональна:
	- В WhatsApp транскрибирует голосовые сообщения.
	- Для других типов файлов сохраняет их в стандартную папку.
